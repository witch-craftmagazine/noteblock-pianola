A fun noteblock player piano! 

Custom model animation made using blockbench, rendered with threejs. All sound is handled with spessasynth and a modified instrument transposed sf2 file.

## Dependencies

- [spessasynth_lib](https://github.com/spessasus/spessasynth_lib)  
  Used for audio synthesis. Licensed under Apache 2.0.

- [three.js](https://github.com/mrdoob/three.js)  
  Used for 3D rendering. Licensed under MIT.
