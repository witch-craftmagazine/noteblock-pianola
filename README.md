A fun noteblock player piano! 

Custom model animation made using blockbench, rendered with threejs. All sound is handled with spessasynth and a modified instrument transposed sf2 file.

Midis sourced from:
- https://pianola.co.nz/public/
- https://musescore.com/
- https://bitmidi.com/
- https://www.zaxpax.com/disney1.htm
- https://torbid.tljhome.com/midi/disney.html
- https://www.midis101.com/
- https://www.midi-karaoke.info/

A few in my library are sourced from the following, but I don't think any are contained in this repo:
- http://www.pianorollmusic.org/rolldatabase.php
- https://github.com/pianoroll/SUPRA
- https://www.kunstderfuge.com/piano-rolls.htm
